# Деплой RehabPlan — инструкция

## Способ 1: GitHub Pages (рекомендуется) — бесплатно, ссылка навсегда

### Шаги:
1. Зайдите на **github.com** → зарегистрируйтесь (если нет аккаунта)
2. Нажмите **"New repository"**
   - Имя: `rehabplan` (или любое)
   - Тип: Public
   - Нажмите **"Create repository"**
3. На странице репозитория нажмите **"uploading an existing file"**
4. Перетащите все 4 файла из папки: `index.html`, `manifest.json`, `sw.js`
5. Нажмите **"Commit changes"**
6. Перейдите в **Settings → Pages → Source** → выберите **"main"** ветку → Save
7. Через 1-2 минуты появится ссылка вида:
   **`https://ВАШ_ЛОГИН.github.io/rehabplan`**

Эту ссылку можно кидать коллегам — открывается на любом устройстве.

## Способ 2: Netlify Drop — 30 секунд, без регистрации

1. Зайдите на **netlify.com/drop**
2. Перетащите всю папку целиком на страницу
3. Получите ссылку вида `https://random-name.netlify.app`
   (можно переименовать в настройках)

## Установка как приложение на телефон

### iPhone (Safari):
1. Откройте ссылку в Safari
2. Нажмите значок **"Поделиться"** (квадрат со стрелкой вверх)
3. Выберите **"На экран «Домой»"**
4. Приложение появится как иконка на главном экране

### Android (Chrome):
1. Откройте ссылку в Chrome
2. Появится баннер **"Добавить на главный экран"** — нажмите
   (или: меню ⋮ → "Установить приложение")
3. Иконка появится на рабочем столе

## Что получаете

- Работает на компьютере, планшете, телефоне
- Тёмная тема автоматически
- Экспорт в Word (.docx) прямо из браузера
- Печать с правильным форматированием
- Офлайн-режим (кэш) для повторного открытия без интернета
- Можно добавить на домашний экран как нативное приложение (PWA)

---

## Важно

Для работы ИИ-функций (PDF-парсинг и генерация комплекса) нужен интернет.
Приложение использует Anthropic API — ключ встроен в Claude.ai и работает только
при открытии через интерфейс claude.ai. При самостоятельном деплое потребуется
добавить собственный API-ключ Anthropic в код (параметр x-api-key в headers).
