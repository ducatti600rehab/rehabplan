# Деплой Telegram-бота RehabPlan

## Шаг 1 — Создай бота в Telegram (2 минуты)
1. Открой Telegram → найди @BotFather
2. Напиши /newbot
3. Имя бота: RehabPlan
4. Username: rehabplan_вашеимя_bot (должен быть уникальным)
5. BotFather пришлёт токен вида: 7234567890:AAF...
6. Скопируй токен — он нужен на следующем шаге

## Шаг 2 — Задеплой на Railway.app (5 минут)
1. Зайди на railway.app → Sign up with GitHub
2. New Project → Deploy from GitHub repo
   (или: New Project → Empty project → Add service → GitHub repo)
3. Выбери репозиторий rehabplan
4. В репозиторий сначала загрузи файлы из этой папки:
   bot.py, requirements.txt, Procfile, runtime.txt
5. В Railway: Variables → добавь переменную:
   BOT_TOKEN = (токен от BotFather)
6. Deploy → подожди 2 минуты

## Шаг 3 — Готово!
Открой Telegram → найди своего бота → /start

Ссылка на бота: t.me/rehabplan_вашеимя_bot
Кидай коллегам эту ссылку!
